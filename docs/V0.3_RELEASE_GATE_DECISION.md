## 4. Waiver 原文（维护者批准记录，2026-09-01）

> **Waiver #1 — unsigned release（延续 v0.2 既定策略）**：v0.3.0 发布安装包与产品
> EXE 不做 Authenticode 签名。已知并接受的风险：SmartScreen/浏览器可能提示"未知
> 发布者"，部分企业策略（AppLocker/WDAC/软件限制策略）可能默认拦截未签名安装包，
> 用户信任链依赖 Release 页面公布的 SHA-256 校验值。缓解：发布页逐产物公布 SHA-256，
> Release Notes 显著披露。批准人：维护者（本仓库唯一维护者），2026-09-01。

> **Waiver #2 — Windows 10 x64 生命周期未验证，支持声明改为仅 Windows 11 x64**：
> 本发布周期无可用 Windows 10 x64 真机/VM，完整安装-升级-卸载生命周期未在
> Windows 10 上执行；公开支持声明同步改为"仅官方支持 Windows 11 x64"，Windows 10
> 用户可自行使用但不获得官方验证声明，未来补齐验证后可能恢复支持。不声称、不暗示
> Windows 10 已验证。批准人：维护者，2026-09-01。

> **Waiver #3 — 非 ASCII Windows 用户目录 GUI 验证未执行（v0.1/v0.2/v0.3 均为
> 已知覆盖缺口）**：v0.3 更换了采集执行方式（自 EXE worker）与 SQLite 统一实现，
> 该场景在 v0.3 上仍未实测；本次明确**不自动沿用 v0.2 waiver**，而是重新批准本
> waiver 并在 Release Notes 披露为未验证场景。ASCII 路径与含空格路径已实测通过。
> 遇到相关问题时由用户报告、按个案处理。批准人：维护者，2026-09-01。
