# v0.3.0 Release Notes（release candidate）

目标平台：**Windows 11 x64** · 安装包：MSI / NSIS · 许可：MIT（第三方声明见
`THIRD_PARTY_NOTICES.md`，随安装包分发）。

## 采集架构重写：单 EXE 隔离 worker

- **不再依赖外部 ccusage CLI**：ccusage v20.0.20 的 Rust 采集源码 vendored 进本仓库
  （可审计：`UPSTREAM.toml` / `PATCHES.md` / `MANIFEST.sha256` / 定价 manifest），
  编译进产品 EXE。
- **同一产品 EXE 的隔离 worker**：采集在产品 EXE 自身的隐藏 worker 模式
  （`--cam-internal-collector-worker-v1`）中执行——单进程批量快照、超时/panic 崩溃
  隔离、single-flight、应用退出后零残留进程。安装包只包含一个可执行文件。
- **无任何 sidecar 回退**：正常构建、运行、安装产物中不存在、不查找、不下载
  `ccusage.exe` / `ccusage-antigravity.exe`。

## Agent 支持

支持 17 个 Agent（开放字符串 ID + Rust 侧 `displayName`，未知 ID 可安全显示）：

Claude Code、OpenAI Codex、OpenCode、Amp、Droid、Codebuff、Hermes、Pi、Goose、
OpenClaw、Kilo、GitHub Copilot、Gemini CLI、Kimi、Qwen Code、Grok CLI、Antigravity。

**Antigravity 为 CAM 维护的 downstream 移植**（基于上游未合并的 PR #1487，
commit `c58c1b3aab2eacc82add250c8229bb6192e4489b`），不是 ccusage 官方支持。
其读取本机未公开稳定 schema，成本为估算值，可能随 Antigravity 更新而失效。

## 批准的值语义变化（相对 v0.2）

1. **reasoning 分类精度提升**：来源明确的 reasoning/thinking tokens 单独计入
   `reasoningTokens`，不再与不可归因残差混入 `unclassifiedTokens`；各类 total 不变。
2. **缺价成本为 null**：某日任一活跃模型缺少定价快照时，该日 `estimatedCostUsd`
   为 `null`——不再伪造 `$0.00`，也不再输出误导性的部分成本（v0.2 的 sidecar 路径
   会把未定价模型静默计为 0）。

## 性能

- 每次完整刷新（17 Agent）：release 实测 median ≈ 75 ms、p95 ≈ 86 ms
  （标准工作负载），远低于 5 分钟周期刷新间隔。
- 首次采集或数据集很大时，冷启动读盘可能显著慢于后续周期刷新（真实机器冷首刷
  观测约数秒）；采集在后台执行，不阻塞界面。

## 隐私与本地性

- 本地运行，**零网络采集**：不联网查询定价、不发送遥测、无账号。
- 所有 Agent 数据库以只读方式打开；应用不修改、不迁移、不锁定任何 Agent 源数据。
- React 前端只消费聚合的 `UsageSummary`，不接触原始日志。

## 支持声明与已知限制（维护者已逐项书面批准的 waiver，2026-09-01）

- **仅官方支持 Windows 11 x64**。Windows 10 x64 的安装生命周期未验证（本发布周期
  无可用 Windows 10 环境）；Windows 10 用户可自行使用但不获得官方验证声明，
  未来补齐验证后可能恢复支持。
- 安装包未经 Authenticode 签名（`NotSigned`）：SmartScreen 可能提示"未知发布者"，
  企业策略可能拦截未签名安装；请在安装前核对 Release 附带的 SHA-256 校验值。
- 非 ASCII Windows 用户目录（用户名/ profile 路径含非 ASCII 字符）下的完整安装与
  采集 GUI 验证未执行（v0.1/v0.2/v0.3 均为已知覆盖缺口）；ASCII 路径与含空格路径
  已验证。遇到问题时请报告，勿假设该场景受支持。
