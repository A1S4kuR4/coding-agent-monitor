# v0.5.0 手动走查清单(2026-09-18)

目的:在 Windows 本机验证 2026-09-18 主界面重构(P0/P1/P2)的全部用户可见行为,并把证据填进
[V0.5_RELEASE_VERIFICATION.md](V0.5_RELEASE_VERIFICATION.md)。走查通过后,在对应条目标 `PASS` 并附截图或一句记录;发现偏差时记录复现步骤即可,不必当场修。

环境基线:Windows 11 x64,系统深色模式,默认窗口 680×700,100% DPI。每节末尾的扩展项(浅色/缩放/reduced-motion)单独再跑。

## 第 0 步:Windows 自动检查(命令,非手动)

```powershell
pnpm install
pnpm lint ; pnpm typecheck ; pnpm test          # 预期 16 files / 152 tests 全绿
pnpm test:e2e                                    # 预期 47 passed(系统 Edge)
pnpm vendor:verify ; pnpm build
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml
```

> 前提:`src-tauri` 的 Claude Desktop 后端(当前未提交)提交后,cargo 三项的结果才覆盖它。

走查用 `pnpm dev`(端口 1420)即可;涉及托盘/生命周期的项等打包后再验。
