# Coding Agent Monitor v0.4.0

Local candidate packages have been built; native release gates remain incomplete.
Actual acceptance is tracked in
[V0.4_RELEASE_VERIFICATION.md](V0.4_RELEASE_VERIFICATION.md).

- Unified freshness and refresh status in the dashboard and tray. Failed
  refreshes keep the last successful snapshot and explain its original date.
- Clearer coverage and unknown-cost explanations, Chinese/English preferences,
  keyboard controls and a more compact dashboard.
- Optional Windows startup and start-hidden behavior, single-instance
  activation, window restoration and a close-to-tray explanation.
- Restore the last successful seven-day aggregate after restarting.
- On-demand seven/thirty-day history with per-day agent/model details. Thirty
  days are never added to the five-minute background collection workload.
- Preference save failures are reported and can be retried.

Collection remains local and offline, using vendored ccusage v20.0.20 and the
CAM-maintained Antigravity port, with the existing 17-agent scope. Cost is an
API reference estimate, not subscription usage or remaining account quota.
T08 delivered research only; this package adds no online account integration.

Target: Windows 11 x64. Packages are unsigned; verify SHA-256 before use.
Windows 10 and a complete non-ASCII Windows user-profile GUI run remain
unverified. Fresh v0.4 acceptance limitations and package hashes are in the
verification record; previous release waivers are not relabelled as passes.
