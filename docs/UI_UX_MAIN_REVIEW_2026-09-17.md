# 主界面 UI/UX 优化分析(2026-09-17)

范围:主窗口 dashboard 视图(`src/App.tsx` + `src/App.css`),以 2026-09-17 深色模式截图(680×~700 默认窗口)为基准。
方法:截图走查 + 代码核对(行号引用),三个方向:视觉与信息层级 / 信息密度与扩展 / 交互与效率。
配套原型:`src/prototypes/optimized-main.html`(可交互,含"当前 ↔ 优化"A/B 切换)。

---

## 0. 总体评价

当前界面的底层决策是健康的,不建议推倒:

- **语义诚实**:delta 不用红绿定性(App.css:60-63)、成本三态区分(有值/缺价/无用量,App.tsx:665-672)、缓存占比口径写明分母——这是同类工具很少做到的,必须保留。
- **可访问性扎实**:焦点环、`prefers-reduced-motion`、每柱完整 aria-label(含 delta 基准,App.tsx:1126-1145)、chip 溢出键盘可达。
- **视觉系统克制**:暖纸墨色调、三套字体分工(Display/Sans/Mono)、agent 身份色集中管理。

问题集中在**主界面层的信息架构**:说明性 chrome 过多、负态信息占位过高、详情层级断裂、以及为将来功能(配额监控)缺少结构预留。以下按方向展开。

---

## A. 视觉与信息层级

### A1. 趋势区 chrome 五行堆叠,稀释了图表本身 —— 优先级 P0

趋势区在图表之前的垂直堆叠(App.tsx:1008-1118):

1. `h2 最近7天` + `合计 222.05M` + 7/30 天按钮(App.tsx:1010-1016)
2. 30 天状态块(App.tsx:1018-1025)
3. 筛选 chips 行(App.tsx:1030-1116)
4. 说明文字"筛选只影响趋势……"(App.tsx:1118)

图表之后还有第 5 行缩放说明(App.tsx:1195-1199)。默认窗口高度下,图表被压到 132px(compact media query,App.css:1236),而说明性文字占了约 110px。**用户要看的是柱,不是规则。**

建议:

- 合并两行说明为一条上下文提示:无筛选时显示缩放口径,有筛选时显示"筛选只影响趋势",二选一,不占两行。
- 7/30 天范围控件从 pill 改为 segmented control(范围与筛选是不同层级,当前同为 pill 造型,App.css:1251-1270 vs 1086-1099,功能语义被视觉同构抹平)。
- 30 天状态块(scope/时区/新鲜度/覆盖度四行 `<p>`)收成一行可展开的元信息。

### A2. Hero 元信息首槽位给了负态 —— 优先级 P1

`预估成本不可用 — 缺少模型价格` 占据 meta 行第一位置(App.tsx:827-843),截图中这是今日摘要区第三醒目的文本。成本缺失是**常态而非异常**(截图当日即是),负态长句常驻首槽会持续消耗注意力。

建议:有价格时正常显示 `$x.xx 预估成本`;缺价时降为一个安静的 `成本 n/a ⓘ` 短标记 + tooltip/关于区解释,把 `约 98% 缓存输入` 提为唯一元信息。三态语义保留,只是负态的视觉权重降下来。

### A3. Hero 大数字与 agent 列表之间缺少"构成"连接 —— 优先级 P1

`25.36M`(App.tsx:819)与下方 Claude Code 22.5M / Codex 2.86M 列表(App.tsx:845-1004)是同一数据的两个层级,但视觉上被 delta、unit、meta 三行隔开,中间没有"构成"线索。

建议:在 meta 行下加一条**细构成条**(单条 3-4px 横向分段条,按 agent 着色),把大数字、agent 列表、趋势图柱的颜色语言缝合起来。这条构成条同时为 B1(Token 构成)提供载体。

### A4. 图表数值标签层级颠倒 —— 优先级 P2

每柱数值标签 0.66rem / ink-3(App.css:568-584),截图中"50.47M"等是界面上最小的数据文本,而它们是图表里唯一的绝对值。建议:数值提为 ink-2 / 0.72rem,"今日"柱(末柱)数值用全 ink 加粗——选中态已有此处理(App.css:549-552),今日应默认享有。

## B. 信息密度与扩展

### B1. Token 构成折叠在页面最底部,且与 meta 重复 —— 优先级 P0

"约 98% 缓存输入"已在 meta 行出现(App.tsx:842),而完整的 Token 构成要滚动到页底手动展开 `<details>`(App.tsx:1279-1294)。这是用户理解"我的 token 花在哪"的核心数据,入口却最深。

建议:今日区内嵌一条**细分段构成条**(输入/输出/缓存读取/缓存创建,中性墨色,App.css:1039-1050 的 2px 比例条思路升级为一条完整构成条),点击展开明细行——用 A3 的同一条构成条做双编码(agent 维度 + 类型维度切换),密度上升而 chrome 不增。

### B2. 30 天视图强制 1672px 横向滚动 —— 优先级 P1

`.trend.trend-30 { min-width: 1672px }`(App.css:1272),默认 680px 窗口意味着看 30 天 = 必须横向滚动,且滚动中丢失表头语境。

建议:30 天模式提供**周聚合 / 日**切换——默认按周聚合成 4-5 根柱(与 7 天视图同构,无滚动),需要日粒度时再切回横向滚动模式。周聚合同时缓解 30 天状态块(A1)的信息量。

### B3. 无扩展槽:配额监控等新功能无处安放 —— 优先级 P1

`docs/QUOTA_MONITOR_FEASIBILITY.md` 表明配额/用量限制监控在评估中。当前 dash-left 是"大数字 + agent 列表"的封闭结构,新功能只能往 dash-details 底部塞折叠 details(设置、关于已在那里),主界面会越来越长。

建议:今日区引入**可插拔卡槽**结构——agent 列表下方预留一个卡片位,配额/预算类功能以同尺寸卡片插入,无数据时不渲染。原型中演示了该槽位形态(配额卡片占位 + 空态隐藏)。

### B4. dash-details 三个 details 视觉权重相同 —— 优先级 P2

Token 构成(核心数据)、关于这些数字(静态说明)、偏好设置(低频操作)三者同为折叠 details(App.tsx:1279-1373),权重无区分。B1 实施后构成前移,剩余"关于 + 设置"两个即可,问题自然消解。

## C. 交互与效率

### C1. 日详情面板:双模式设计合理,但点击模式无可发现性 —— 优先级 P0

hover tooltip + click 钉住面板的双层设计(App.tsx:1203-1273)本身是好的,但柱体没有任何"可点击"的视觉线索——hover 亮度微增(App.css:563-566)只暗示了 tooltip。用户不点一次就永远不知道 panel 存在,而 panel 里有模型级明细,是深钻的唯一入口。

建议:首次进入时默认选中"今日"柱(选中态样式已有,App.css:544-556),panel 默认展开今日详情——既演示了交互,又让最常用的"今天各模型明细"零点击可达。

### C2. "返回今日"按钮位置不固定 —— 优先级 P1

该按钮条件性地插入 section-heading 行(App.tsx:1015),出现时会把标题行撑成两行(`.section-heading:has(.history-controls)` flex-wrap,App.css:1277)。建议移入 panel 内部右上角作为关闭按钮,位置恒定。

### C3. 刷新链路反馈完整但缺"自动"感知 —— 优先级 P2

手动刷新 spinner + header 时间戳 + stale banner 已闭环(App.tsx:749-804)。但 focus 触发刷新(App.tsx:359-383)和托盘定时刷新对用户不可见——时间戳跳动时用户不知道发生了什么。建议时间戳旁加一个极轻的刷新中状态点(已有 `collection.refreshing` 状态可复用),或在 tooltip 说明"窗口聚焦时自动刷新"。

### C4. 已做得好的交互,保持 —— 记录

chip 溢出 details 键盘可达(App.tsx:1063-1115)、tooltip 视口钳制(App.tsx:480-511)、Escape 清选中(App.tsx:1164-1169)、选中日按 ISO date 追踪防错位(App.tsx:288-292)——这些是正确的复杂度,不要在新设计中丢失。

| P1 | B2 30 天周聚合 | chartView 增加聚合模式 | 消除强制横滚 |

## E. 原型说明

`src/prototypes/optimized-main.html`:单文件、深色主题、使用 2026-09-17 截图真实数据(7 日总量 222.05M / 今日 25.36M / Claude Code 22.5M / Codex 2.86M;agent 日级拆分为示意估算,已在原型内标注)。

可交互点:

- 顶部"当前 ↔ 优化"切换,同数据对比两版布局;
- 构成条:agent 维度 / 类型维度切换(B1+A3);
- 趋势区:范围 segmented control、筛选 chips、点击柱看钉住详情(今日默认选中,C1);
- 30 天:周聚合 ↔ 日模式(B2);
- 配额卡槽占位与空态(B3)。

原型仅演示布局与交互,不接真实数据管道;落地时按 D 表拆分改动。
