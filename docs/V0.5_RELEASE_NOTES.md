- Main-screen redesign (2026-09-18, review `UI_UX_MAIN_REVIEW_2026-09-17` and
  marks appendix `UI_UX_MARKS_AND_CONTROLS_2026-09-17`):
  - A thin token-composition strip under today's figure with by-agent /
    by-type dimensions and an expandable detail, so the core "where did the
    tokens go" answer needs no scroll; each agent row gains a share sliver.
  - The current window's last day (today) is pinned by default, so the
    day-detail panel with model-level breakdown is reachable with zero
    clicks; the panel owns a fixed close button.
  - The trend area speaks with one context line instead of two note rows, and
    the 30-day status block collapses into a single expandable meta line.
- 30-day window defaults to a week aggregation — five real merged 7-day
  buckets, structurally identical to the 7-day view with no horizontal
  scroll; the "By day" mode keeps the existing scrollable per-day view. Week
  comparisons state their basis ("vs previous week") and a partial current
  bucket never renders a misleading delta.
- Control language rework: filter chips become underline text tabs with the
  agent-coloured active underline, range/aggregation controls become mono
  kicker tabs, secondary actions become underlined text — the ring-plus-
  monogram agent marks are replaced by redrawn stroke-only sigils
  (`src/assets/agent-marks/`), coloured only through the `--agent-*` tokens.
- An unpriced cost demotes to a quiet `Cost n/a ⓘ` short mark; the concrete
  reason moves to its tooltip and the statistics explainer. The three cost
  states (priced / missing prices / no usage) remain distinct and never
  collapse into a fake `$0.00`.
- Chart value labels rise to a readable tier, and today's bar carries the
  strongest label; a quiet dot beside the header timestamp shows when any
  refresh (focus, tray, periodic included) is in flight.
- Main-screen implementation commits: `dfe8690` (P0 trend chrome, composition
  strip, today pinned), `45ba1a2` (P1 sigils, underline tabs, cost demotion,
  weekly aggregation), `c46aac2` (P2 label hierarchy, refresh dot); follow-ups
  `5e2dfe8` (680×700 fit, e2e stability) and `0343b19` (day-detail model-list
  text hierarchy).
